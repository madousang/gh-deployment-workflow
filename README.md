# GitHub Actions Deployment Workflow

A minimal static site deployed to GitHub Pages using a GitHub Actions workflow.

## What this does

Every push to `main` that changes `index.html` triggers a GitHub Actions
workflow (`.github/workflows/deploy.yml`) that deploys the site to GitHub Pages.

Live site: https://madousang.github.io/gh-deployment-workflow/

## Project

Built as a solution to the
[GitHub Actions Deployment Workflow](https://roadmap.sh/projects/github-actions-deployment-workflow)
project on roadmap.sh, to practice CI/CD concepts and GitHub Actions workflows.
